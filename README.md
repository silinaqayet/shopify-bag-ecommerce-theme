# Shopify Bag E-commerce Theme Customizations

Custom Shopify storefront components developed for a bag e-commerce project during a software engineering internship.

This repository contains a **portfolio sample of custom Liquid/CSS work created on top of Shopify's Atelier theme**. The full base theme, store settings, credentials, product/customer data, and private configuration are intentionally excluded.

## Technologies

- Shopify Liquid
- CSS
- JavaScript
- Shopify section schema
- Shopify metafields / metaobjects
- Shopify CLI
- Judge.me styling

## Included Components

- Flip collection cards with CSS 3D hover interaction
- Responsive collection tabs/carousel
- “Wear It Your Way” product content using metafields/metaobjects
- “Closer Look” product image/callout section
- Sticky product add-to-cart bar
- Luxury collection slider
- Custom Judge.me storefront styling

## Example Custom Data Sources

Some components use product-specific Shopify metafields/metaobjects such as:

```
product.metafields.custom.wear_it_looks
product.metafields.custom.closer_look_main_image
product.metafields.custom.closer_look_callouts
product.metafields.custom.disc_color
```

## Repository Scope

This is **not a standalone Shopify theme**. It is a portfolio code sample containing representative custom components developed on top of the Atelier base theme.

No Shopify Admin credentials, API tokens, store-specific settings, customer data, or private database information are included.
